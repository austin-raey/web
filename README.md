Code for my personal site, [raey.me](https://raey.me).

# Notable Technologies

- [Astro](https://astro.build): For building the site.
- CSS: Just regular CSS for this site, no [Tailwind](https://tailwindcss.com)!
- [ESLint](https://eslint.org) + [Prettier](https://prettier.io):  code formatting and linting, with the following notable plugins:
	- [eslint-plugin-perfectionist](https://github.com/azat-io/eslint-plugin-perfectionist), love this for sorting
	- [eslint-plugin-unicorn](https://github.com/sindresorhus/eslint-plugin-unicorn), like some of the rules here. Still discovering whether or not I like this.
	- Notable mention [Biome](https://biomejs.dev). Not quite there yet for Astro projects, so remains unimplemented for now.

- [iconify](https://iconify.design): easy way to add icons.

A full list is in the [`package.json`](./package.json)!
